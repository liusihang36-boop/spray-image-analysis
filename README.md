# 喷雾图像分析（Spray Image Analysis）

用于高速摄影喷雾序列的 MATLAB 图像处理，以及三束独立喷雾/塌缩合并整体喷雾的双模式测量。

## 当前功能

- 自动识别圆形可视窗口，并依据实际直径 170 mm 建立像素—长度标定。
- 仅处理喷射开始后 0–5 ms 的图像，支持 25,000 fps 连续拍摄序列。
- 以第一帧为背景，生成喷雾二值掩膜、差分图、恢复像素图及叠加预览图。
- 自动搜索喷嘴候选坐标，并提供人工修改、局部放大和确认预览。
- 将喷雾划分为左束、中束、右束，提供分界线预览和修改。
- 分别计算贯穿距、轴向贯穿距、投影面积、锥角、截面宽度和下游展开角。
- 将左、中、右三束分别输出到独立工作表和 CSV。
- 保存质量检查日志、边界诊断、测量设置和可视化结果。
- 高温塌缩或合并后切换到整体喷雾模式，不再强制输出左、中、右伪结果。

## 文件

- `src/spray_preprocess_trial.m`：序列预处理和二值化。
- `src/spray_measure_threejets.m`：三束喷雾几何参数测量。
- `src/spray_measure_merged.m`：塌缩/合并整体喷雾几何参数测量。
- `run_validation_threejets.m`：三束独立模式入口。
- `run_validation_mergedspray.m`：整体合并模式入口。

## 使用顺序

1. 在 MATLAB 中运行 `spray_preprocess_trial`，选择包含原始 BMP 序列的目录。
2. 检查生成的背景、掩膜、差分图和叠加图。
3. 未合并工况运行 `run_validation_threejets`；塌缩/合并工况运行 `run_validation_mergedspray`。
4. 依次确认窗口标定、喷嘴坐标和三束分界线。
5. 检查对应模式的测量表、质量检查日志和代表帧预览。

批量入口 `run_validation_batch` 会逐工况确认多束参考、整体或旧三束模式，
并记录 `analysis_mode.txt`。

## 固定实验条件

- 相机帧率：25,000 fps。
- 第一帧：背景帧。
- 第二帧：喷射计时零点。
- 喷油脉宽：5 ms。
- 可视窗口实际直径：170 mm。
- 当前对象：多束参考分析与合并整体喷雾；旧三束保留用于对照。

这些参数在代码中保留为可调整配置。更换相机、喷油脉宽或窗口尺寸时应同步修改。

## 当前验证状态

当前版本属于研究试用版。预处理流程已根据代表帧多次调整；测量程序新增了基于灰度主体的锥角和下游展开角测量，用来补充二值外包络角度缺失问题。该新增部分尚需在 MATLAB 中通过完整序列验证，不能仅凭自动质量标记认定为有效实验结果。

建议每次修改后保留以下验证材料：

- 运行所用源代码快照；
- `measurement_settings.mat` 和 `运行记录.csv`；
- 左、中、右三束测量表；
- 质量检查日志、边界与前端诊断；
- 1、2、3 ms 代表帧预览；
- 问题帧对应的原始 BMP、二值掩膜和截面采样文件。

## 20260922_review2：旋转遮挡与多束复核版

本版为待完整序列验证的修订，尚未在本开发环境执行 MATLAB。

- 首次逐工况圈选每台旋转风扇的**完整扫掠范围**（不是当前叶片轮廓），保存
  `obstruction_settings.mat`。重新安装相机后删除该文件重新确认。排除区内不能测量；
  本方法不恢复遮挡喷雾。单张图的暗区不能安全自动区分叶片与深色喷雾。
- `multi_plume` 支持2至8个参考方向，先生成整体结果，再按早期清晰帧人工选定
  参考扇区。不是自动五束跟踪；不会在后期强行给模糊喷束重新编号。接触分界或
  遮挡的参考束角度标为缺失。逐束结果在 `多束参考测量.xlsx` 中，批量总表的
  multi_plume 行为整体结果，不能误当逐束汇总。
- 整体与多束模式每次在原图预览喷嘴位置并允许修改，不再直接接受默认Y=20。
- `ConeAngle_deg` 改为0.15–0.60轴向长度区间内，各可见截面喷嘴张角的中位数；
  `DownstreamAngle_deg` 为0.55–0.85区间的同类量。与旧的边界斜率夹角不能混画。
  `FitSlopeAngle_deg` 单独保存旧的直线边界拟合量。保留有符号半角，不把负值钳成0。
- `FixedStationAngle_deg` 是30 mm固定轴向位置±5像素带的可见截面张角，用于
  前端截断而该截面仍完整的情况；位置可在p.fixedStation_mm配置，比较时须统一。
- `VisibleRadialExtent_mm` 是当前可见区域长度。前端触边或支撑不足时正式贯穿距
  及依赖其完整长度的比例角置NaN，不将可见长度冒充完整贯穿距。
- 单背景帧输出一次信息提示，记录backgroundFrameCount与noiseEstimateQuality；
  固定灰度门限仍有效，但不声称已估计可靠的帧间噪声。
- 高温输出是未分相的光学衰减区域。灰度主体不等于液相，弱衰减区域不等于气相；
  本版未实现经验证的气液分相，不输出气相贯穿距或气液面积比。

运行 `test_visible_angle` 检查理想角度、坐标平移、遮挡端点和截面不足，再运行
`run_validation_batch`。本版会重新确认模式：多束参考分析、整体喷雾、保留旧三束。
旧三束仅用于对照。原始输入必须包含确认无喷雾的第一背景帧及随后连续帧；
仅1/3/5 ms的叠加图不能用于重新计算轮廓或验证分割有效率。



## 20260926_review3：边界分类与运行追溯

- 多束分区分别保存原始物理可见区与参考扇区。`WindowTouch` 只表示物理
  边界接触，`SectorContact` 表示参考分界接触；不再因任意位置触边直接清空全部角度。
  接触参考分界的独立束身份仍不确定，`Reliable=false`。表中的局部角仅为
  参考扇区内可见截面量，不可直接作为已确认的独立喷束锥角。
- 测角截面仍排除物理边界和参考分界上的端点。新增覆盖率及中文缺失原因。
  比例位置依赖完整长度，轴向或径向前端截断、前端支撑不足时继续置缺失，
  同时清空依赖长度的近场宽度及拟合角。固定30 mm截面量独立判定。
- 叠加图蓝点显示实际参与张角统计的截面端点，不再将拟合直线配上截面张角。
- `run_validation` 不再默认为旧三束；未传模式时必须选择。默认几何配置改为
  各原始工况目录内保存，避免不同工况共用仓库级参数。显式传入配置仍可使用。
- `run_validation` 在测量前和成功结束后写入 `run_manifest.json`，记录Git提交、
  未提交状态、实际函数路径、模式、MATLAB版本及参数路径。失败时保留pending阶段。
  直接调用底层测量函数不会生成此入口记录。Git提交未知或工作区不干净时，
  不能只凭提交编号复现实验，需同时保留源代码与配置。

本轮未执行MATLAB及真实序列回归；静态解析不代表数值或科学有效性验证。
在本机先运行 `test_visible_angle`，再显式运行
`run_validation(原始工况目录, [], "multi_plume")` 或 `"merged_spray"`。
先验证300 K无风扇、500 K无风扇、300 K旋转风扇三组，保存运行记录、
